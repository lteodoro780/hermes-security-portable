# Uso offline

O pacote `.exe` funciona offline sem instalar Python. Na edição por código-fonte, Python e as dependências precisam estar instalados. Perfis, histórico, benchmark, relatórios, referências, preferências, Base Local, monitoramento, incidentes e backups ficam dentro da pasta portátil. O monitor, os diagnósticos, a pesquisa de documentos, o fluxo de incidentes e as exportações HTML/PDF não precisam de modelo. Somente os recursos que geram texto com IA exigem `llama.cpp` e o modelo GGUF. O gerenciador de modelos precisa de internet durante o download.
