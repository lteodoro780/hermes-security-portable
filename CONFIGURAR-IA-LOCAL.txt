CONFIGURAR IA LOCAL NO HERMES 0.9.0 DESKTOP
===================================

A janela desktop funciona sem estes arquivos. Para habilitar o Assistente IA:

METODO RECOMENDADO

1. Abra a secao Modelos no HERMES.
2. Selecione qualquer arquivo .gguf ou escolha um perfil para baixar.
3. Localize llama-server.exe ou llama.exe.
4. Clique em Iniciar IA.

PERFIS

- Rapido: Qwen3-1.7B-Q8_0.gguf, aproximadamente 1,83 GB.
- Balanceado: Qwen3-4B-Q4_K_M.gguf, aproximadamente 2,50 GB.
- Qualidade: Qwen3-8B-Q4_K_M.gguf, aproximadamente 5,03 GB.

METODO MANUAL

1. Obtenha uma compilacao do llama.cpp para Windows ou use:

   winget install llama.cpp

2. Se usar os binarios portateis, copie todos para:

   tools\llama.cpp\

3. Confirme que este arquivo existe:

   tools\llama.cpp\llama-server.exe

4. Obtenha um modelo GGUF e selecione-o na secao Modelos. O HERMES pode usar
   o arquivo no local atual ou copia-lo para a pasta models depois de validar.

5. Execute novamente INICIAR-HERMES.bat.

O HERMES controlara o motor local e mostrara "IA ativa" quando ele estiver pronto.

IMPORTANTE

- Confira a licenca e a origem antes de baixar qualquer modelo.
- Nao use modelos maiores do que a memoria disponivel no notebook.
- Em video integrado, mantenha Camadas na GPU em 0 inicialmente.
- Os diagnosticos locais continuam disponiveis se a IA estiver offline.
