HERMES SECURITY PORTABLE 0.9.0 — DESKTOP NATIVO
================================================

COMO ABRIR

1. Extraia o ZIP inteiro para uma pasta comum, como Documentos\HERMES.
2. Execute HERMES-Security-Portable-0.9.0.exe.
3. A janela do HERMES abrirá diretamente. Não é usado navegador.

Não é necessário instalar Python. Na primeira abertura, o assistente mostra o
hardware detectado e permite configurar a IA. Você pode concluir sem modelo:
monitor, diagnósticos, incidentes, relatórios e backup continuam funcionando.

COMO ADICIONAR UM MODELO

1. Abra a seção Modelos.
2. Clique em Selecionar arquivo .gguf.
3. Escolha se deseja usar o arquivo no local atual ou copiá-lo para models.
4. Localize llama-server.exe ou llama.exe, caso ainda não esteja instalado.
5. Clique em Iniciar IA.

O HERMES valida o cabeçalho GGUF antes de registrar o arquivo. Ele também pode
baixar um dos modelos oficiais sugeridos pela própria tela Modelos.

PARA O COMPUTADOR COM 16 GB DE RAM

O perfil Balanceado — Qwen3 4B Q4_K_M — continua sendo o ponto de partida
recomendado. Modelos maiores podem funcionar, mas deixam menos memória livre.

PORTABILIDADE

config   configurações do aplicativo e da IA
data     histórico, monitoramento, incidentes e Base Local
logs     registro do llama.cpp
models   modelos GGUF copiados ou baixados
reports  relatórios gerados
tools    llama.cpp opcional

AVISO DO WINDOWS

Esta compilação de teste ainda não possui assinatura digital comercial. O
SmartScreen pode exibir um aviso. Confira o SHA-256 fornecido antes de decidir
usar Mais informações > Executar assim mesmo.

PRIVACIDADE

A interface desktop chama os módulos locais diretamente. Ela não inicia um
servidor HTTP e não abre o navegador. Os dados permanecem na pasta portátil.
